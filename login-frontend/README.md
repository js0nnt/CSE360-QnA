# Login frontend prototype

This folder preserves the original Swing prototype and artwork from the
`login-frontend` branch. The running QnA app uses JavaFX instead. Its active
login and signup screens are in `src/resources/com/template/login.fxml` and
`src/resources/com/template/signup.fxml`, with shared styling in
`src/resources/com/template/auth.css`.

The JavaFX login uses the prototype's background image. The signup screen
uses its blue and white visual style while retaining the fields supported by
the current `UserStore` (username and password). The extra prototype fields
are visual concepts and are not collected or stored by the running app.
